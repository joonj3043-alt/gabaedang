# 시안 분석과 구현 기준

PC 시안은 상단 로고·중앙 메뉴·네이비 상담 버튼, 좌측 2행 헤드라인, 우측 검은 라이더, 히어로 하단에 겹친 3열 서비스 카드, 도시 풍경으로 이어지는 철학·대표 문구, 네이비 상담 바, 간결한 푸터 순서입니다.

모바일 시안은 흰색 로고, 햄버거와 빠른 메뉴 행, 흰색/시안 헤드라인, 우측 하단 라이더, 아이콘 중심의 가로형 서비스 카드 3개, 세로로 이어지는 철학과 대표 문구, 3열 상담 바입니다.

헤더는 스크롤 후 반투명 흰색으로 변경됩니다. 카드 이미지 확대·화살표 이동은 CSS로 구현하며 reduced-motion 사용자는 전환 효과를 끕니다. 모바일에는 전용 세로 라이더 사진을 사용합니다.

원본과의 차이: 사진을 새로 생성했으므로 라이더 방향, 건물과 다리 배치가 다릅니다. 로고 원본과 손글씨 서체는 제공되지 않아 대체했습니다. 실제 회사 정보 대신 준비 상태를 표시하고, 서비스 미확정 항목에는 확인 필요 문구가 포함됩니다.

## 재검수 최종 보정

최종 수치는 refinement.css를 우선합니다. PC 헤드라인 최대 76px, PC 카드 1.12:1, 모바일 카드 101~104px, 모바일 헤더 76px, 모바일 상담 바 가로형 아이콘·문구로 조정했습니다. 변경 이유와 시안 대비 평가 및 잔여 차이는 QA.md에 기록했습니다.
